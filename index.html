⚙ Ajustes de generación

El modo demo genera imágenes abstractas directamente en tu navegador con canvas. Es perfecto para probar la interfaz: respeta seed, steps y CFG, y no necesita ninguna API. Cambia de proveedor cuando quieras conectar un servicio real.
Pollinations.ai es una API pública, gratuita y sin clave. Tus prompts se envían a pollinations.ai para generar las imágenes (puede haber límites de velocidad). Admite prompt, tamaño y seed; no admite steps, CFG, prompt negativo ni imagen de referencia. Modelos habituales: flux (calidad) y turbo (rápido).
Conecta tu propia API: se envía un POST JSON con prompt, negative_prompt, width, height, seed, steps, cfg_scale, model y se espera una imagen (base64 en JSON, formato OpenAI o binaria). Si tu API usa otros campos, adapta buildCustomPayload() en js/providers.js.
